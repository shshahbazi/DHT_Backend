# Doost Backend – Developer Habit Tracker

This repository contains the **Django backend** for **Doost**, a developer-focused habit tracker.  
It was developed as part of a **Bachelor’s final project**.  

The backend provides APIs for user profiles, habits, reminders, and real-time notifications to help developers improve productivity, maintain healthy routines, and support mental well-being.

---

##  Features
-  **User Profiles** – personal settings and preferences  
-  **Habit & To-do Management**  
-  **Custom Reminders** – scheduled with **Celery & Redis**  
-  **Health & Productivity Rules** – reminders for any developer health rule (e.g., 20-20-20 eye care, posture checks, stretching exercises, etc.)  
-  **Web Push Notifications** – delivered via **Firebase Cloud Messaging (FCM)**  
-  **Reports & Analytics** – track work hours and habit compliance  

---

##  Tech Stack
- **Backend Framework**: Django  
- **Async Tasks**: Celery + Redis  
- **Database**: PostgreSQL  
- **Notifications**: Django Channels, WebSockets, Firebase (Web Push)
